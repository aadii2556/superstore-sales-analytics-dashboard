## Executive Business Intelligence Solution for Retail Analytics

An enterprise-grade Power BI dashboard designed to analyze retail sales performance, profitability trends, customer segmentation, and regional business metrics through interactive executive-level reporting.

---

## Project Overview

This project transforms raw retail transactional data into actionable business intelligence using Power BI, DAX, and advanced visualization design.

---

## Features

- State-wise sales analytics
- Profitability analysis by city
- Customer segment tracking
- Interactive filtering
- KPI monitoring
- Category performance insights
- Executive dashboard reporting

---

## Tech Stack

- Power BI
- DAX
- Power Query
- Data Visualization
- Business Intelligence
